Website Building

Lister.cards

Designed and built Lister.cards, a web-based SaaS platform that helps collectible card sellers create and manage eBay variation listings more efficiently. I developed the product around real seller workflows, including searchable card sets, inventory and quantity selection, pricing, draft saving, CSV export, and direct eBay integration for publishing listings. The project combines product design, responsive web development, backend functionality, account management, and third-party API integration in one platform.

PRODUCER FIX

Designed and developed Producer Fix, a music marketplace built to connect producers and artists through beat discovery, licensing, and direct sales. The platform combines producer storefronts, beat sales, exclusive auctions, live streaming with real-time chat and bidding, private offers, and sales management tools into one integrated experience. The project showcases my experience in website development, UI/UX design, database architecture, backend functionality, and building complex, feature-rich digital platforms.
